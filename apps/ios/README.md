# Apex for iOS

Native SwiftUI app. Design and roadmap: [`docs/mobile/architecture.md`](../../docs/mobile/architecture.md).

- Bundle id: `com.apex.kubemanager.mobile`
- Minimum iOS: 17.0
- The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is **not committed**.

## Layout

| Path | What |
|---|---|
| `project.yml` | XcodeGen spec (targets, settings, scheme) |
| `ApexKube/` | App target: `App/` entry point, `Features/` screens |
| `Packages/ApexKubeCore/` | SwiftPM package with no UIKit/SwiftUI deps (`Triage` today; kubeconfig, credentials, client later) |

## Build locally

Needs Xcode (CI uses 16.4) and XcodeGen 2.46.0 (`brew install xcodegen`).

```bash
cd apps/ios
xcodegen generate
open ApexKube.xcodeproj          # or build from the CLI:

# Core package tests on the Mac host (fast, no simulator)
(cd Packages/ApexKubeCore && swift test)

# App build + tests on a simulator, unsigned
xcodebuild test -project ApexKube.xcodeproj -scheme ApexKube \
  -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO
```

Pick any installed iPhone simulator (`xcrun simctl list devices available`). Signing and TestFlight come later (PR8).

CI: `.github/workflows/ios.yml`, runs only on changes under `apps/ios/**` or `spec/**`.
